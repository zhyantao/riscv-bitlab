输入数字

自动识别：0x 前缀或含 A–F 的整数按十六进制，纯数字按十进制。纯数字十六进制请加 0x。仅接受非负整数，最多 4096 个字符。不支持科学计数法；例如 1e3 会按十六进制解析为 483。

1 B = 1 字节；1 MB = 1,000,000 B，1 MiB = 1,048,576 B。内存容量常用 1024 进制，标准单位为 KiB / MiB / GiB / TiB。

使用 BigInt 精确计算，完整显示有限小数，不进行浮点近似或四舍五入。大于 64 位的值仍参与完整换算，位图仅显示低 64 位；翻转时保留高位。
